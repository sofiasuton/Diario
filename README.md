# Diario

Espacio de journaling con consignas de escritura y escritura libre.

- 9 consignas (Memoria, Hoy, Cartas, Cambios, Cuerpo, Gratitud, Miedos, Sueños, Lugares) + consigna al azar
- Escritura libre
- Cada entrada guarda fecha, título opcional y texto
- Buscador por título, texto, consigna o fecha
- Archivo, racha de días y resumen de la semana
- Exportar / importar una copia en `.json`

Las entradas se guardan en el navegador (`localStorage`): quedan en ese dispositivo y en ese navegador. Usá **Exportar copia** para tener un respaldo o pasarlas a otro dispositivo.

Es un solo archivo, `index.html`, sin dependencias. Se puede publicar con GitHub Pages.
